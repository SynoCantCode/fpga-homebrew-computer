; PALETTE.TXT: the pixel screen's colours. On the card as /SYSTEM/DESIGN/PALETTE.TXT, read at every start-up.
; Edit it on the computer:  run edit.bin system/design/palette.txt   then reboot (or type: colour load)
; Numbers are hex, without 0x. A line starting with ; is a note. Words after the colour are a note too.
;
;   family N RRGGBB   colour family N (1-E) gets 16 shades, from almost black (shade 0) through RRGGBB
;                     itself (shade 8) to almost white (shade F). A dot of colour 4, shade A = 4A.
;   NN RRGGBB         one colour number NN (00-FF), exactly RRGGBB. F0-FF are the 16 free colours.
;
; Family 0 is the greys (00 black ... 0F white): set those one at a time if you want them different.
; A line that's missing here keeps the colour the ROM starts with (sw/graphics/designs/palette.asm).
